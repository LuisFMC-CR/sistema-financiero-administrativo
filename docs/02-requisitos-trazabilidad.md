# Requisitos y trazabilidad

## Convenciones

- `RF`: requisito funcional.
- `RN`: regla de negocio.
- `RNF`: requisito no funcional.
- `UC`: caso de uso.
- `PR`: prueba.
- `ADR`: decisión arquitectónica.
- `EV`: evidencia.

Estados: **Propuesto**, **Aprobado**, **En desarrollo**, **Implementado**, **Verificado** o **Descartado**.
